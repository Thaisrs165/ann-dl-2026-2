    Exercises → MLP

    Implementation approach. The network lives in a single module, code/mlp.py: an MLP class that takes the layer sizes (e.g. [2, 8, 1] or [4, 16, 16, 3]) and the loss as arguments. Activations, losses, the forward pass, the backward pass (every gradient derived by hand, no autodiff) and the gradient-descent update are written in plain numpy; no TensorFlow, PyTorch or MLPClassifier is used. scikit-learn is used only for make_blobs, make_classification, train_test_split, confusion_matrix and the LogisticRegression baselines the statement asks for. Exercises 2, 3 and 4 each have their own script, and all of them import the same MLP class without modifying it — Exercise 3 only changes arguments (layer_sizes, loss="cce", hyperparameters), and Exercise 4 only changes layer_sizes.

    Every script creates one rng = np.random.default_rng(42) and passes it to the network, which uses it for the initial weights and for the mini-batch shuffle of every epoch; the dataset generators and the split use random_state=42 as prescribed. The only exception is the seed study of Exercise 4B, which by design repeats the comparison with default_rng(43) and default_rng(44) as well. To reproduce everything, run from the repository root:

    # -----------------------------------------------------------------------------
# Activations
# -----------------------------------------------------------------------------
def tanh(u: np.ndarray) -> np.ndarray:
    return np.tanh(u)


def tanh_derivative_from_output(h: np.ndarray) -> np.ndarray:
    """d/du tanh(u) = 1 - tanh(u)^2, written in terms of h = tanh(u)."""
    return 1.0 - h ** 2


def sigmoid(u: np.ndarray) -> np.ndarray:
    # Clipping only avoids overflow in exp for very large |u|; it does not
    # change the value in any range the network actually reaches.
    return 1.0 / (1.0 + np.exp(-np.clip(u, -500, 500)))


def softmax(u: np.ndarray) -> np.ndarray:
    """Row-wise softmax. Subtracting the row max leaves the result unchanged
    (it cancels between numerator and denominator) but keeps exp() finite."""
    e = np.exp(u - u.max(axis=1, keepdims=True))
    return e / e.sum(axis=1, keepdims=True)


# -----------------------------------------------------------------------------
# Losses -- each one is an (output activation, loss value) pair
# -----------------------------------------------------------------------------
EPS = 1e-12  # keeps log() away from log(0)


def binary_cross_entropy(y_hat: np.ndarray, y: np.ndarray) -> float:
    """L = -(1/N) sum[y log y_hat + (1 - y) log(1 - y_hat)], y in {0, 1}, shape (N, 1)."""
    y_hat = np.clip(y_hat, EPS, 1 - EPS)
    return float(-np.mean(y * np.log(y_hat) + (1 - y) * np.log(1 - y_hat)))


def categorical_cross_entropy(y_hat: np.ndarray, y: np.ndarray) -> float:
    """L = -(1/N) sum_n sum_k y_nk log y_hat_nk, y one-hot, shape (N, K)."""
    return float(-np.mean(np.sum(y * np.log(np.clip(y_hat, EPS, 1.0)), axis=1)))


# name -> (output activation, loss function)
LOSSES = {
    "bce": (sigmoid, binary_cross_entropy),
    "cce": (softmax, categorical_cross_entropy),
}

    class MLP:
    """Fully connected network: tanh on every hidden layer, sigmoid/softmax on the output."""

    def __init__(self, layer_sizes: list[int], loss: str, rng: np.random.Generator):
        if len(layer_sizes) < 3:
            raise ValueError("need at least one hidden layer: [n_in, hidden..., n_out]")
        self.layer_sizes = list(layer_sizes)
        self.output_activation, self.loss_fn = LOSSES[loss]

        # Xavier/Glorot-style initialisation: W ~ N(0, 1/fan_in). It keeps the
        # pre-activations of each layer at roughly unit scale, so tanh starts
        # in its non-saturated region and gradients neither vanish nor explode.
        # W[l] has shape (fan_in, fan_out) so that a batch is X @ W + b.
        self.W = [rng.normal(0.0, np.sqrt(1.0 / n_in), size=(n_in, n_out))
                  for n_in, n_out in zip(layer_sizes[:-1], layer_sizes[1:])]
        self.b = [np.zeros(n_out) for n_out in layer_sizes[1:]]

    def n_parameters(self) -> int:
        return int(sum(W.size + b.size for W, b in zip(self.W, self.b)))

    # ---- forward pass -------------------------------------------------------
    def forward(self, X: np.ndarray) -> list[np.ndarray]:
        """Return the activations of every layer, input included: [X, h1, ..., y_hat].

        Hidden layer l: u = h_{l-1} W_l + b_l, h_l = tanh(u).
        Output layer:   u = h_{L-1} W_L + b_L, y_hat = sigmoid(u) or softmax(u).
        The list is kept because the backward pass needs every h_l.
        """
        activations = [X]
        h = X
        last = len(self.W) - 1
        for l, (W, b) in enumerate(zip(self.W, self.b)):
            u = h @ W + b
            h = self.output_activation(u) if l == last else tanh(u)
            activations.append(h)
        return activations

    # ---- backward pass ------------------------------------------------------
    def backward(self, activations: list[np.ndarray], y: np.ndarray):
        """Gradients of the mean loss w.r.t. every W_l and b_l, by the chain rule.

        Output layer: for sigmoid+BCE and for softmax+CCE alike,
            delta_L = dL/du_L = (y_hat - y) / N.
        Then, walking from the last layer to the first:
            dL/dW_l = h_{l-1}^T delta_l,    dL/db_l = sum over the batch of delta_l,
            dL/dh_{l-1} = delta_l W_l^T,
            delta_{l-1} = dL/dh_{l-1} * (1 - h_{l-1}^2)      (tanh derivative).
        """
        n = y.shape[0]
        grads_W = [np.empty_like(W) for W in self.W]
        grads_b = [np.empty_like(b) for b in self.b]

        delta = (activations[-1] - y) / n
        for l in range(len(self.W) - 1, -1, -1):
            h_prev = activations[l]
            grads_W[l] = h_prev.T @ delta
            grads_b[l] = delta.sum(axis=0)
            if l > 0:  # no gradient needed w.r.t. the input X itself
                delta = (delta @ self.W[l].T) * tanh_derivative_from_output(h_prev)
        return grads_W, grads_b

    # ---- parameter update ---------------------------------------------------
    def update(self, grads_W, grads_b, eta: float) -> None:
        """Plain gradient descent: theta <- theta - eta * dL/dtheta."""
        for l in range(len(self.W)):
            self.W[l] -= eta * grads_W[l]
            self.b[l] -= eta * grads_b[l]

    # ---- helpers built on the three steps above ----------------------------
    def loss(self, X: np.ndarray, y: np.ndarray) -> float:
        return self.loss_fn(self.forward(X)[-1], y)

    def predict_proba(self, X: np.ndarray) -> np.ndarray:
        return self.forward(X)[-1]

    def predict(self, X: np.ndarray) -> np.ndarray:
        p = self.predict_proba(X)
        if p.shape[1] == 1:                      # binary: threshold the sigmoid at 0.5
            return (p[:, 0] >= 0.5).astype(int)
        return p.argmax(axis=1)                  # multi-class: most probable class

    def fit(self, X: np.ndarray, y: np.ndarray, eta: float, epochs: int,
            batch_size: int, rng: np.random.Generator) -> list[float]:
        """Mini-batch gradient descent. Each epoch reshuffles the training set
        with `rng`, then runs forward -> backward -> update once per batch.
        Returns the full-training-set loss measured at the end of every epoch."""
        history = []
        n = X.shape[0]
        for _ in range(epochs):
            order = rng.permutation(n)
            for start in range(0, n, batch_size):
                idx = order[start:start + batch_size]
                activations = self.forward(X[idx])
                grads_W, grads_b = self.backward(activations, y[idx])
                self.update(grads_W, grads_b, eta)
            history.append(self.loss(X, y))
        return history

    Exercise 1

    One Step of Backpropagation, by Hand

    Network: 2 inputs → 2 hidden \(\tanh\) units → 1 \(\tanh\) output, loss \(L=(y-\hat y)^2\). Given: \(\mathbf{x}=[0.5,\,-0.2]\), \(y=1.0\), \(\mathbf{W}^{(1)}=\begin{bmatrix}0.3 & -0.1\\ 0.2 & 0.4\end{bmatrix}\), \(\mathbf{b}^{(1)}=[0.1,\,-0.2]\), \(\mathbf{W}^{(2)}=[0.5,\,-0.3]\), \(b^{(2)}=0.2\), \(\eta=0.3\). Row \(i\) of \(\mathbf{W}^{(1)}\) holds the weights into hidden unit \(i\). All values are done by hand below and rounded to 6 decimals (intermediate values were carried at full precision).

    A — Forward pass

    Hidden pre-activations \(\mathbf{z}^{(1)}=\mathbf{W}^{(1)}\mathbf{x}+\mathbf{b}^{(1)}\):

    \[ \begin{aligned} z^{(1)}_1 &= 0.3(0.5) + (-0.1)(-0.2) + 0.1 = 0.15 + 0.02 + 0.1 = 0.270000\\ z^{(1)}_2 &= 0.2(0.5) + 0.4(-0.2) + (-0.2) = 0.10 - 0.08 - 0.2 = -0.180000 \end{aligned} \]

    Hidden activations \(\mathbf{h}^{(1)}=\tanh(\mathbf{z}^{(1)})\):

    \[ h^{(1)}_1=\tanh(0.27)=0.263625,\qquad h^{(1)}_2=\tanh(-0.18)=-0.178081 \]

    Output pre-activation \(u^{(2)}=\mathbf{W}^{(2)}\mathbf{h}^{(1)}+b^{(2)}\):

    \[ u^{(2)} = 0.5(0.263625) + (-0.3)(-0.178081) + 0.2 = 0.131812 + 0.053424 + 0.2 = 0.385237 \]

    Output and loss:

    \[ \hat y=\tanh(0.385237)=0.367247,\qquad L=(1-0.367247)^2=(0.632753)^2=0.400377 \]

    B — Backward pass

    Start at the output.

    \[ \frac{\partial L}{\partial \hat y} = -2(y-\hat y) = -2(0.632753) = -1.265507 \]

    Through the output \(\tanh\), using \(\frac{d}{du}\tanh(u)=1-\tanh^2(u)=1-\hat y^2\):

    \[ 1-\hat y^2 = 1-0.367247^2 = 0.865130,\qquad \frac{\partial L}{\partial u^{(2)}} = \frac{\partial L}{\partial \hat y}(1-\hat y^2) = -1.265507 \times 0.865130 = -1.094828 \]

    Output layer. Since \(u^{(2)}=\sum_i W^{(2)}_i h^{(1)}_i + b^{(2)}\), we have \(\partial u^{(2)}/\partial W^{(2)}_i = h^{(1)}_i\) and \(\partial u^{(2)}/\partial b^{(2)}=1\):

    \[ \begin{aligned} \frac{\partial L}{\partial W^{(2)}_1} &= -1.094828 \times 0.263625 = -0.288624\\ \frac{\partial L}{\partial W^{(2)}_2} &= -1.094828 \times (-0.178081) = 0.194968\\ \frac{\partial L}{\partial b^{(2)}} &= -1.094828 \end{aligned} \]

    Propagate back to the hidden layer. \(\partial u^{(2)}/\partial h^{(1)}_i = W^{(2)}_i\):

    \[ \frac{\partial L}{\partial h^{(1)}_1} = -1.094828 \times 0.5 = -0.547414,\qquad \frac{\partial L}{\partial h^{(1)}_2} = -1.094828 \times (-0.3) = 0.328448 \]

    Through the hidden \(\tanh\): \(1-(h^{(1)}_1)^2 = 1-0.263625^2 = 0.930502\) and \(1-(h^{(1)}_2)^2 = 1-0.178081^2 = 0.968287\), so

    \[ \frac{\partial L}{\partial z^{(1)}_1} = -0.547414 \times 0.930502 = -0.509370,\qquad \frac{\partial L}{\partial z^{(1)}_2} = 0.328448 \times 0.968287 = 0.318032 \]

    Hidden layer. \(z^{(1)}_i=\sum_j W^{(1)}_{ij}x_j + b^{(1)}_i\), so \(\partial L/\partial W^{(1)}_{ij} = (\partial L/\partial z^{(1)}_i)\,x_j\) and \(\partial L/\partial b^{(1)}_i = \partial L/\partial z^{(1)}_i\):

    \[ \frac{\partial L}{\partial \mathbf{W}^{(1)}} = \begin{bmatrix} -0.509370(0.5) & -0.509370(-0.2)\\ 0.318032(0.5) & 0.318032(-0.2) \end{bmatrix} = \begin{bmatrix} -0.254685 & 0.101874\\ 0.159016 & -0.063606 \end{bmatrix}, \qquad \frac{\partial L}{\partial \mathbf{b}^{(1)}} = [-0.509370,\; 0.318032] \]

    C — Parameter update

    \(\theta \leftarrow \theta - \eta\,\partial L/\partial\theta\) with \(\eta = 0.3\):

    Parameter Old Gradient \(-\eta\cdot\)gradient New
    \(W^{(2)}_1\) 0.5 −0.288624 +0.086587 0.586587
    \(W^{(2)}_2\) −0.3 0.194968 −0.058490 −0.358490
    \(b^{(2)}\) 0.2 −1.094828 +0.328448 0.528448
    \(W^{(1)}_{11}\) 0.3 −0.254685 +0.076405 0.376405
    \(W^{(1)}_{12}\) −0.1 0.101874 −0.030562 −0.130562
    \(W^{(1)}_{21}\) 0.2 0.159016 −0.047705 0.152295
    \(W^{(1)}_{22}\) 0.4 −0.063606 +0.019082 0.419082
    \(b^{(1)}_1\) 0.1 −0.509370 +0.152811 0.252811
    \(b^{(1)}_2\) −0.2 0.318032 −0.095410 −0.295410

    (The statement counts "eight parameters"; the network actually has nine — 4 + 2 + 2 + 1 — and all nine are updated above.)

    Would the loss go up or down on a second forward pass? Down. Every parameter moved in the direction opposite to its gradient, and to first order the change in loss is \(\Delta L \approx -\eta\,\lVert\nabla L\rVert^2 = -0.3 \times 1.785141 = -0.535542 < 0\). Intuitively: the prediction \(\hat y = 0.3672\) is too low for the target 1, so the update pushes \(u^{(2)}\) up — \(b^{(2)}\) grows, \(W^{(2)}_1\) grows because \(h^{(1)}_1>0\), \(W^{(2)}_2\) becomes more negative because \(h^{(1)}_2<0\) — and the hidden layer moves its activations in the directions that help. Repeating the forward pass of item A with the new parameters gives \(\mathbf{z}^{(1)}=[0.467126,\,-0.303079]\), \(\mathbf{h}^{(1)}=[0.435874,\,-0.294127]\), \(u^{(2)}=0.889568\), \(\hat y=0.711181\) and \(L=0.083417\), down from 0.400377. The actual drop (0.316960) is smaller than the first-order estimate because \(\eta=0.3\) is a large step and the loss is curved; the sign, however, is what the gradient guarantees for a small enough step, and here it holds.

    C — Implement the MLP

    Approach. The MLP class (shown at the top of this page) is used with layer_sizes=[2, 8, 1] and loss="bce": 2 inputs → 8 \(\tanh\) hidden units → 1 sigmoid output, binary cross-entropy loss. Weights start at \(\mathcal N(0, 1/\text{fan\_in})\), biases at zero. Training is mini-batch gradient descent: each epoch reshuffles the training set with the shared rng, and every batch runs forward → backward → update; the full training-set loss is recorded at the end of each epoch.

    For a sigmoid output \(\hat y=\sigma(u)\) with BCE \(L=-\frac1N\sum[y\log\hat y+(1-y)\log(1-\hat y)]\), using \(\sigma'(u)=\hat y(1-\hat y)\): \(\frac{\partial L}{\partial u}=\frac1N\left(-\frac{y}{\hat y}+\frac{1-y}{1-\hat y}\right)\hat y(1-\hat y) =\frac1N(\hat y-y)\). That is the delta = (activations[-1] - y) / n line in backward; from there each hidden layer uses the \(\tanh\) derivative \(1-h^2\), exactly as in Exercise 1.

    D — Analysis

    What Figure 3 shows. The region the MLP assigns to Class 1 is two disconnected pieces: one in the upper-right and one in the lower-left, separated by a diagonal blue band (Class 0) that runs from upper-left to lower-right through the origin. Along the line \(x_1=x_2\) — where both Class 1 clusters sit — the prediction switches from 1 to 0 at \(t\approx-1.58\) and back to 1 at \(t\approx 1.62\): Class 1 is predicted for \(t<-1.58\) and for \(t>1.62\). The network built this from two roughly parallel boundaries — each hidden \(\tanh\) unit contributes a soft straight cut, and the output combines them into "outside the band".

    Why no single straight line can do it. A straight line splits the plane into two half-planes, and a half-plane is convex: if it contains two points, it contains the segment between them. Here the two Class 1 centres \((3,3)\) and \((-3,-3)\) have the Class 0 centre \((0,0)\) exactly at their midpoint. Any half-plane that contains both Class 1 clusters must therefore contain the Class 0 cluster as well. The best a line can do is give up on one Class 1 cluster — for example, the line \(x_1+x_2=3\), halfway between \((0,0)\) and \((3,3)\), scores 0.6850 on the test set.

    Why logistic regression is below 50%, not just below 90%. The data are point-symmetric around the origin: flipping \((x_1,x_2)\to(-x_1,-x_2)\) maps Class 1 onto itself and Class 0 onto itself. Any tilt of the line that helps with one Class 1 cluster hurts equally with the other, so the cross-entropy-optimal line is degenerate — \(\mathbf w\approx 0\). The fitted \(\mathbf w=[0.0296, 0.0015]\) confirms it: every prediction is within 0.05 of 0.5, so which side of 0.5 a point falls on is decided by sampling noise in the fitted coefficients, not by any structure in the data. The result is essentially a coin flip, and this particular coin landed at 0.4750. The MLP does not need a line: the hidden layer maps the points to a space where "outside the diagonal band" becomes linearly separable for the output unit, which is why it reaches 0.9200.

    B — Adapt the network

    What changed: only arguments. The same MLP class from mlp.py is imported unchanged: forward, backward and update are the same lines of code that trained the binary network. Exercise 3 passes layer_sizes=[4, 16, 3] (three output units) and loss="cce", which plugs in softmax as the output activation and categorical_cross_entropy as the loss; the labels are converted to one-hot vectors with one_hot. This works because softmax + categorical cross-entropy has the same output gradient as sigmoid + BCE, derived below.

    Deriving \(\partial L/\partial u\) for softmax + cross-entropy. For one sample with output pre-activations \(u_1,\dots,u_K\), one-hot target \(\mathbf y\) (\(\sum_k y_k=1\)) and

    \[ \hat y_k=\frac{e^{u_k}}{\sum_{m} e^{u_m}},\qquad L=-\sum_k y_k\log\hat y_k . \]

    Step 1 — derivative of softmax. By the quotient rule, with \(S=\sum_m e^{u_m}\):

    \[ \frac{\partial \hat y_k}{\partial u_j}= \begin{cases} \dfrac{e^{u_k}S-e^{u_k}e^{u_k}}{S^2}=\hat y_k(1-\hat y_k) & j=k\\[2ex] \dfrac{0-e^{u_k}e^{u_j}}{S^2}=-\hat y_k\hat y_j & j\neq k \end{cases} \quad=\;\hat y_k(\delta_{kj}-\hat y_j). \]

    Step 2 — chain rule through the loss. \(\partial L/\partial\hat y_k=-y_k/\hat y_k\), so

    \[ \frac{\partial L}{\partial u_j} =\sum_k\left(-\frac{y_k}{\hat y_k}\right)\hat y_k(\delta_{kj}-\hat y_j) =-\sum_k y_k\delta_{kj}+\hat y_j\sum_k y_k =-y_j+\hat y_j\cdot 1 . \]
    \[ \boxed{\;\frac{\partial L}{\partial u_j}=\hat y_j-y_j\;} \qquad\text{(and }\tfrac1N(\hat{\mathbf y}-\mathbf y)\text{ for the mean over a batch of }N\text{)} \]

    Why it is so simple. The \(1/\hat y_k\) from the log cancels the \(\hat y_k\) factor of the softmax derivative, and the normalisation \(\sum_k y_k=1\) removes the sum. The result is just "prediction minus target", with no softmax Jacobian left — the same expression as for sigmoid + BCE in Exercise 2 (the sigmoid is the \(K=2\) case of the softmax). That is why backward can start every network with delta = (activations[-1] - y) / n without knowing which loss is in use. It also explains why the gradient never vanishes for a confident wrong answer: if \(\hat y_j\to 0\) for the true class, \(\partial L/\partial u_j\to -1\), the largest it can be.

    C — Analysis

    What was measured. The second hidden layer did not improve test accuracy: the mean over three seeds is 0.8467 for both networks, a difference of +0.00 percentage points. The per-seed differences (+1.67, −0.33, −1.33 pp) have both signs and are as large as the seed-to-seed spread of each model by itself (standard deviation 1.20 pp for Exercise 3), so there is no detectable effect of depth here.

    The training loss tells a different story from the test accuracy. In Figure 6 the deeper network reaches a clearly lower training loss (0.2111 vs 0.2803) and a higher training accuracy (0.9222 vs 0.8978) — so it is not failing to optimize. But none of that gain reaches the test set: the gap between train and test accuracy grows from 5.1 pp to 7.6 pp. The extra 272 parameters are being used to fit the training points more tightly, i.e. to memorize the particular points that fall in the overlap between clusters, which do not generalize.

    Why, from the structure of the data. The data have only 6 Gaussian clusters in 4-D. A boundary that separates them only has to be roughly piecewise linear between neighbouring clusters, and one hidden layer of 16 \(\tanh\) units already provides 16 cuts to build it — Exercise 2 showed that a single hidden layer is enough to give one class several disconnected regions. What limits accuracy at ~85% is not the shape of the boundary but the overlap between clusters of different classes (Exercise 3D): points on the wrong side of an overlap cannot be fixed by any model, deep or shallow. A second layer adds representational power — it can compose the first layer's cuts into more complex regions — but this dataset has no extra structure for that power to capture.

    What the extra layer costs. Three times as many parameters (403 vs 131), more computation per epoch, a noisier loss curve (Figure 6: at the same \(\eta\), each mini-batch update moves the deeper model's loss more, so the curve is less smooth), and more capacity to overfit. In this experiment the optimization cost did not materialize as slower training — the deeper network actually descended faster per epoch — but the generalization cost did: lower training loss, same test accuracy.

    What kind of data would reward the extra depth. Data with hierarchical or compositional structure, where useful features are built out of simpler features: images (edges → textures → parts → objects), audio, or text. Also synthetic problems whose boundary is a composition of many simple pieces — a checkerboard or a parity function with many cells, nested or interleaved spirals — where a shallow network would need exponentially many hidden units to draw all the regions, while a deeper network can reuse the same first-layer cuts and combine them. With enough data to avoid overfitting, that is where a second hidden layer pays off.
